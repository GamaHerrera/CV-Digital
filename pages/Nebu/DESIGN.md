# DESIGN.md - Nebú Social Club

This document is generated by `/impeccable document`. It acts as the ultimate source of truth for the project's design system. Do not deviate from these rules unless explicitly instructed.

## 1. Design Philosophy
The design reflects the "We Reject The Real" manifesto. It is dark, immersive, and purposefully avoids standard, predictable web aesthetics. It leans into the feeling of a late-night, underground rave—where shadows are as important as light.

## 2. Design Tokens
The design is powered by CSS custom properties located in `style.css`.

### Colors
- **Backgrounds**: `--bg-primary` (`#0A0A0A`), `--bg-secondary` (`#000000`), `--bg-card` (`#0D0D0D`)
- **Brand Accent**: `--brand-accent` (`#E50914` - Blood Red), `--brand-accent-dim` (`#8B0000`)
- **Text**: `--text-primary` (`#F5F5F5`), `--text-muted` (`#888888`), `--text-faint` (`#666666`)
- **Borders**: `--border-subtle` (`#1A1A1A`), `--border-mid` (`#2A2A2A`)

### Typography
- **Headings & Display** (`--font-display`): 'Syncopate', 'Space Grotesk', sans-serif. Used for brutalist, wide titles (often tracked out with `letter-spacing: 0.05em` to `0.2em`).
- **Body & Technical** (`--font-body`): 'JetBrains Mono', 'Roboto Mono', monospace. Used for raw, technical body copy, buttons, and meta tags.

### Sizing & Layout
- **Radii**: `--radius-sm` (2px), `--radius-md` (4px). Avoid rounded corners. Keep things sharp.
- **Container**: Max width `--container-max` (1200px) with `1.25rem` padding (mobile) scaling to `2rem` (tablet+).
- **Section Padding**: Vertical padding scales dynamically via clamp: `clamp(4rem, 10vw, 8rem)`.

## 3. Visual Signatures (Effects)
This aesthetic relies heavily on analogue distortion and subtle background animations to break "digital perfection".
- **Film Grain**: A persistent noise filter (`.film-grain`) running at `0.045` opacity over the entire viewport, shifting at `0.08s` intervals.
- **Glitch Text**: Core text elements use a multi-layered CSS glitch effect (`.glitch`, `.glitch-sm`) that separates red (`--brand-accent`) and cyan (`#00ffff`) channels on hover or via JS intersection.
- **Chroma Button Glitch**: `.btn-primary` hover states trigger a `chromaGlitch` on the text, rapidly cycling through cyan, red, magenta, and green text shadows.
- **Organic Orbs**: The hero section uses heavily blurred (`filter: blur(40px)`) radial gradients (`.hero-orb`) drifting organically via CSS keyframes.

## 4. Component Library

### Buttons (`.btn`)
- **Base Style**: Inline-flex, tracked-out uppercase monospace (`letter-spacing: 0.15em`), font-size `0.75rem`, sharp radius (`2px`).
- **Primary (`.btn-primary`)**: Red background (`#E50914`), solid red border. Hover triggers a red box-shadow and the inner text glitch.
- **Secondary (`.btn-secondary`)**: Transparent background, mid-gray border. Hover changes border/text to red with a subtle red glow.

### Navigation (`.navbar`)
- Fixed positioning.
- When scrolled, applies a glassmorphic dark blur (`rgba(10, 10, 10, 0.92)` with `backdrop-filter: blur(12px)`).
- Logo image features a custom 3-channel glitch effect on hover.

### Section Headers (`.section-header`)
- **Tag (`.section-tag`)**: Looks like a comment (e.g. `// PRÓXIMOS EVENTOS`). Small (`0.7rem`), highly tracked (`0.3em`), brand red.
- **Title (`.section-title`)**: Massive clamped display font (`clamp(2.5rem, 8vw, 5rem)`), uppercase, often paired with the glitch effect.

### Event Cards (`.event-card`)
- **Surfaces**: Dark backgrounds (`#000000` / `#0D0D0D`) with subtle `1px` borders (`#1A1A1A`).
- **Interaction**: On hover, the border brightens to `#2A2A2A` and the card translates up by `-4px`. Never use soft drop-shadows.

## 5. Anti-Patterns (What to avoid)
- **NO soft rounded corners** (e.g., `border-radius: 8px` or `12px`).
- **NO typical bright blue/purple AI gradients**.
- **NO stock, clean, friendly photography**.
- **NO generic sans-serif fonts** like Inter or Roboto for headers.
- **NO bright white backgrounds**. Only `#0A0A0A` or darker.
